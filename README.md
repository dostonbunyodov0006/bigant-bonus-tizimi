# BIGANT — ходимлар бонуси ва рағбатлантириш тизими

**Муаллиф:** Достон Бунёдов ([@dostonbunyodov0006](https://github.com/dostonbunyodov0006))

Телеграм бот ва Mini App: ишхона ходимлари ва ҳайдовчиларининг қўшимча иш вақти, юк олиш/топшириш бонуси,
рағбатлантириш, огоҳлантириш ва жарималарини автоматик ҳисоблайди ва Excel ҳисобот беради.

- **Иш вақти:** «Ишни бошладим / тугатдим» тугмалари, соатлик тариф бўйича дақиқа аниқлигида ҳисоб
- **Ҳайдовчилар:** гуруҳга ташланган расмлардан юк бонуси (такрор расм, бир мижоз — битта юк), «Тошкентга кирдим» (GPS)
- **Рағбатлантириш · Огоҳлантириш · Жарима:** ходим танлаш, гуруҳга эълон, жарима вариантлари
- **Excel:** ҳар бир ходимга шахсий файл, раҳбарга умумий ҳисобот, давр 16-дан 15-гача
- **Технологиялар:** Cloudflare Workers, D1 (SQLite), KV, Svelte 5, Telegram Bot API / Mini Apps

> ⚠️ Бу — **портфолио учун нусха**. Ишлаётган тизимга уланмаган. Ходимларнинг исмлари, Telegram ва гуруҳ
> рақамлари **сохтасига алмаштирилган** («Ходим01», «Раҳбар»…). Махфий калитлар йўқ.
> Код фақат кўриш учун — қаранг [LICENSE](LICENSE).
